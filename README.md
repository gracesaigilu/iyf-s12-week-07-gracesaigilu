
# Week 7: Modular ES6 To-Do Application

A fully refactored, production-ready To-Do application built with vanilla JavaScript using a modular ES6 architecture.

## Key Features
* Dynamic DOM Rendering: Efficiently renders filtered lists (All, Active, Completed) and updates task counts dynamically.
* Persistent Storage: Tasks are automatically saved and loaded using the browser's localStorage.

## Project Structure

├── index.html          # Main HTML entry point (loads as module)
├── styles.css          # Application styles
└── js/
    ├── app.js          # Main entry point & event listeners
    ├── state.js        # Central state management
    ├── storage.js      # LocalStorage API handler
    ├── todo-logic.js   # Pure functions for task operations
    └── ui.js           # DOM manipulation and rendering
